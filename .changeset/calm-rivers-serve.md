"@rustrak/server": "minor"

The server serves the dashboard. `apps/webview-ui` (Next.js) is replaced by `apps/dashboard`, a Vite and TanStack Router SPA compiled to static files that the same Actix process hands out at `/`, so one container answers the page and the API on one origin: the session cookie is first-party and no CORS applies to the dashboard. The sign-in page moves from `/auth/login` to `/login`, since `/auth` is the API's namespace; every other address is unchanged. `RUSTRAK_DASHBOARD_DIR` says where the build is (default `./static`) and `RUSTRAK_DASHBOARD=off` keeps a built image API-only; an image built without a dashboard serves the API as before. `rustrak/rustrak-ui` continues as nginx in front of the same bundle, proxying `/api`, `/auth`, `/health`, `/docs` and `/api-docs` to `RUSTRAK_API_URL` for a dashboard hosted away from its server: ~30 MB, under 15 MB idle, trailing slashes dropped and a path refused at start, and the server's certificate verified on an https upstream. The `ui` service leaves `docker-compose.yml` by default and comes back under the `ui` profile. The version check runs in the browser against the release feed rather than in a server process. No schema change.
